Tres ingenierías para dirigir un agente

Prompt engineering

alcance: una interacción

Diseñar el mejor input al modelo: instrucciones, restricciones, ejemplos. Un intercambio pedido-respuesta.

la base Instrucciones claras, vocabulario técnico, ejemplos.

Context engineering

alcance: una sesión

Controlar qué ve el modelo durante toda la tarea: qué se carga, qué se mantiene, qué se descarta. La ventana de contexto como recurso a gestionar.

operaciones Compactar, resetear, exponer información de a poco.

Harness engineering

alcance: múltiples sesiones

Diseñar el entorno completo: qué tools tiene, qué guardrails lo frenan, qué scripts deterministas usa, qué feedback loops cierran el ciclo.

mecanismos Validación automática, permisos, scripts que el agente no puede saltar.

Los tres alcances se anidan: prompt ⊂ context ⊂ harness. Cualquier prompt vive dentro de una sesión; cualquier sesión, dentro de un harness.

"Tres ingenierías que se diferencian por su alcance — el lapso de tiempo y el número de interacciones sobre las que operan. Las introduzco una por una."

"Prompt engineering: una sola interacción. Diseñar el mejor mensaje, las instrucciones, las restricciones, los ejemplos. Es lo que vienen practicando en las semanas anteriores. No desaparece — sigue siendo la base. Pero es solo el primer nivel."

"Context engineering: una sesión completa. La ventana de contexto pasa a ser un recurso a gestionar — qué se carga al principio, qué se mantiene cuando el loop itera, qué se descarta cuando se llena. Es una habilidad nueva que entra en juego apenas el agente trabaja sobre algo no trivial."

"Harness engineering: múltiples sesiones. Acá ya no estás pensando en un mensaje ni en una conversación — estás pensando en el entorno completo en que el agente opera. Qué tools tiene a disposición. Qué guardrails lo frenan cuando va a hacer algo riesgoso. Qué scripts deterministas se ejecutan que el modelo no puede saltar. Cómo se cierra el feedback loop cuando algo falla. Es donde vive la responsabilidad de la que hablamos en el slide anterior."

"Los tres alcances se anidan: cualquier prompt vive dentro de una sesión, cualquier sesión vive dentro de un harness. Lo que sigue de la clase abre los dos niveles nuevos. Y la parte 2 — Claude Code — va a llenar cada uno con features concretas."
